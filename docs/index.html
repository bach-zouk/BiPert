BiPert: How Far Can Linear Go?

A unified linear framework for single-cell perturbation modelling

Abhishek SharmaAleksej Zelezniak
Randall Centre for Cell & Molecular Biophysics, King's College London, London, UK
Paper arXiv Code and notebooks GitHub Data bundles link to follow

Large CRISPR screens measure how thousands of gene knockdowns change the state of a cell, but only in a few cell lines. Two questions follow. Can the effect of a knockdown be predicted in a cell line where it was never measured? And, given a perturbed cell, can the gene that was knocked down be identified?

We show that one linear decomposition answers both. BiPert predicts effects in an unseen cell line, BiPert-FS adapts to a new line from as few as ten measured knockdowns, and BiPert-ID identifies the knocked-down gene with no training. Knockdowns whose effects transfer well between cell lines are also the easiest to identify.

Two tasks

Transfer (forward). The effects of all knockdowns are known in several source cell lines. In a new line only a few are measured. Predict the rest.

Identification (inverse). Given the expression of a perturbed cell and the control cells of its line, rank 1,157 candidate genes by how likely each is the one knocked down. The cell line was never seen in training.

Transfer to an unseen cell line

Let yp,ℓ be the effect of knockdown p in cell line ℓ: the mean expression of its cells minus the mean of that line's control cells, over G genes.

BiPert-FS: few observed knockdowns

With ten or twenty measured knockdowns there is too little data to fit a model for the new line from scratch. BiPert-FS starts from the average effect in the source lines, ȳp, and corrects it inside a basis Φ of 30 response programs:

ŷp = ȳpsource average + Φbshift + Φ(C − I)Φ⊤ȳprescale and mix programs

The shift b and the matrix C are fitted by ridge regression, with C pulled towards the identity, so with no data the model returns the source average.

Identifying the knocked-down gene

BiPert-ID: training-free identification

  1. Prototype. For each knockdown, take its effect in every training line, remove the response that all knockdowns of that line share, and average across lines.
  2. Query. Take the cell's change relative to its line's controls and remove the response shared by the query cells.
  3. Score. Add two standardised signals: the cosine between the query and the prototype, and the drop in expression of the candidate gene itself.

A two-way link between transfer and identification

Recognising a knockdown in a new cell line is like recognising a person by their voice in a new room. If someone's voice sounds the same in every room you have heard them in, you will know them in a new one. If it sounds different each time, you won't, whatever method you use.

Transfer predicts identification

Think of each knockdown as having a signature: the pattern of gene changes it causes. Knockdowns with a consistent signature across cell lines are the ones that are easy to recognise in a new cell line.

  1. Give each knockdown a transfer score, using the training lines only.
  2. Sort the knockdowns into four equal groups by that score, from the lowest transfer score to the highest.
  3. Go to the held-out line and count how often each group is identified. For each knockdown, take its cells in the new line and ask the method to name the gene. It counts as a success if the true gene is among the top 10 guesses.

Identification limits transfer

In an independent screen that activates 1,833 transcription factors in fibroblasts and in RPE-1 cells, a factor that can be identified within both cell types usually transfers between them (25 of 33): its profile in one cell type picks it out among all factors in the other. One that can be identified within neither almost never transfers (8 of 1,720).
